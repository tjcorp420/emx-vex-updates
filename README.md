# EMX VEX updates

Public update channel for EMX VEX. This repository contains release metadata and checksums; application source is maintained in a separate private repository.

[Download the latest Windows release](https://github.com/tjcorp420/emx-vex-updates/releases/latest).

VEX 1.0.0 is the commercial licensed edition. A product-specific VEX purchase key is required by setup and normal startup. Download the Setup EXE for per-user installation. Existing in-app update controls use the portable ZIP: extract the entire package, open EMX-VEX and launch **EMX VEX.exe**, keeping **App** beside it. Activation and settings are saved separately from the application folder.

`latest.json` identifies the stable version, official download URL, package size and SHA256. Releases contain compiled application files, setup and checksums. They contain no source code or credentials. Older pre-license versions are historical releases.
