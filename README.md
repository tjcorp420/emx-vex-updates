# EMX VEX updates

Public update channel for EMX VEX. This repository contains only release metadata and checksums. Application source is maintained separately.

[Download the latest Windows portable release](https://github.com/tjcorp420/emx-vex-updates/releases/latest).

Extract the entire portable ZIP, open EMX-VEX and launch **EMX VEX.exe**. Keep the **App** folder beside the launcher.

`latest.json` identifies the current stable version, official download URL, package size and SHA-256. The downloadable application package is attached to the release.
